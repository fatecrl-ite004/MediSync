# MediSync

Sistema de agendamento e comunicação médica — protótipo acadêmico v0.5, revisão de entrega de **15/11/2026**.

O MediSync reúne agenda, acompanhamento de consultas e mensagens em uma interface web responsiva. A área do paciente prioriza poucas ações por tela, linguagem simples e agendamento em três etapas; a área médica reúne agenda, pacientes fictícios e registros demonstrativos.

> Demonstração com dados fictícios. Login simulado, persistência JSON e chamadas simuladas, sem captura de câmera ou microfone. O projeto não está pronto para operação clínica ou comercial; a revisão não certifica conformidade integral com a LGPD ou WCAG.
